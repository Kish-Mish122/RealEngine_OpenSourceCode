## Инструкция по установке и настройке

#### Введение
SCons - программа с открытым исходным кодом для автоматизации сборки программных проектов, написанный на Python

#### Начало
1. Скачайте данный проект в ZIP-архив
2. **Распакуйте** данный ZIP-архив в удобную вам папку
3. ***Редактируйте!*** Прямо в папке откройте скрипт и отредактируйте его

#### Сборка
1. Скачайте mingw64 и откройте его
2. Через cd пройди в ваш путь с основными скриптами (выглядит так: cd /d/source_realengine)
3. Пропишите команду ***scons platform=windows target=editor -j****
4. Ждите примерно 20-40 минут, пока все файла не забилдиться в папку bin
5. После этого, вы сможете зайти в движок

*После параметра -j можно указать количество ядер вашего процессора. Например, если у вас 4 ядра, можно выставить значение 4, если 8 — то восемь. Это нужно для ускорения сборки движка. НО! Если у вас 4 ядра, а вы укажете 8, сборка будет идти в два раза медленнее. Вы можете не указывать этот параметр — тогда SCons будет использовать значение по умолчанию.*

#### Полезные программы
1. *OpenIDE* - программа для программирования, полезна тем, что можно сразу же залить исходник на Github, для того чтобы не потерять.
2. *Inkscape* - программа для рисования иконок для вашего движка. Сразу можно выбрать формат иконок 16x16, 32x32, 64x64, 128x128, специальный раздел с иконками. Можно сразу же форматировать в SVG, что нужно для движка.
3. *Visual Studio* и *Visual Studio Code* - замена *OpenIDE*. Популярная программа для программирования.
4. *Krita* - замена *Inkscape*. Минусы: нельзя сразу форматировать SVG и довольно низкое качества просмотра.

Удачи в создании ваших движков!
