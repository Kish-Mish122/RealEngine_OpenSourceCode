## Игровой движок:

**[Real Engine](https://www.k1shm1sh-realengine.ru)** - игровой движок для создания игр, где вам открыты все дороги вашей фантазии!

## Бесплатный и открытый исходный код

Создавайте 2D, 3D, Шутеры, Мультиплеерные игры и многое-многое другое что придёт вам в голову!

Начал создавать 20 ноября 2025 году.

## Real Store
Также, в движке есть поддержка Assets Store где вы можете скачать любой скрипт или модельку

## Real Script
Свой язык программирования - RLScript
