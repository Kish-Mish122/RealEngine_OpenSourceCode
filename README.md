## Инструкция по установке и настройке

#### Введение
SCons - программа с открытым исходным кодом для автоматизации сборки программных проектов, написанный на Python

#### Начало
1. Скачайте данный проект в ZIP-архив
2. **Распакуйте** данный ZIP-архив в удобную вам папку
3. ***Редактируйте!*** Прямо в папке откройте скрипт и отредактируйте его

#### Сборка
1. Скачайте mingw64 и откройте его
2. Через cd пройди в ваш путь с основными скриптами (выглядит так: cd /d/source_realengine)
3. Пропишите команду: 

`bash`
	
	scons d3d12=no* beta=yes* -j*
	
4. Ждите примерно 20-40 минут, пока все файла не забилдиться в папку bin
5. После этого, вы сможете зайти в движок

`d3d12=no - не обязательный параметр. Если у вас видеокарта поддерживает DirectX 12 и есть драйвер, то вы можете скомпилировать без параметра d3d12=no`

`beta=yes - не обязательный параметр. Если движок в бета-версии, то можно прописать параметр beta=yes. В оригинальном Real Engine, вместе с параметром beta=yes, будет активирована таймбомба. 
Вы можете настроить коды под себя, чтобы код выполнял функцию, если условие beta выполнено. 
Можно также использовать следующие параметры: beta=yes, release=yes, early=yes. Каждый из них может выполнять отдельную функцию, если условие beta, release, early успешно выполняется.
Если не указывать данный параметр, Real Engine будет использовать заглушку "Unknown version"`

`-j* - не обязательный параметр. Его можно использовать для ускорение компиляции движка. Например: scons d3d12=no beta=yes -j8 - значит, 8 ГБ ОЗУ будет занято под компиляцию. НО! Если у вас 4 ГБ ОЗУ, а вы указали 8, то компиляция может быть ещё дольше.`

**Первая сборка (или сборка после очистки), обычно занимает от 20-40 минут, а после
сборки, SCons будет собирать только те скрипты, которые вы изменили**

## Перевод и локализация
#### Начало
1. Зайдите по пути: 
`editor/translations/editor`.
2. Там будет один файл: `ru.po` - откройте через блокнот или ваш редактор кода

#### Добавление перевода
1. Стандартный перевод (по умолчанию английский) - *msgid*
2. Перевод на русский (или ваш) - *msgstr*

Напрмер:

`msgid code`

	msgid "Hello World"
	msgstr "Привет Мир"

#### Если сломался перевод
Если у вас сломался перевод (например, если нет вообще перевода, всё на английском),
то лучше всего запустить консольную версию движка и посмотерть, что не так с переводом.
Если у вас вместо msgid ——> mgsid (или подобное), то просто измените.

*Вы можете добавить перевод на ваш родной язык (см. в документацию Godot).*

***Properties - перевод настроек***

### Полезные программы
1. *[OpenIDE](https://openide.ru/)* - программа для программирования, полезна тем, что можно сразу же залить исходник на Github, для того чтобы не потерять. И самое главное - **Open Source**, так как разработчик **должен знать, в чём он работает**.
2. *[Inkscape](https://inkscape.org/ru/)* - программа для рисования иконок для вашего движка. Сразу можно выбрать формат иконок 16x16, 32x32, 64x64, 128x128, специальный раздел с иконками. Можно сразу же форматировать в SVG, что нужно для движка. Также **Open Source**
3. *[Visual Studio](https://visualstudio.microsoft.com/ru/)* и *[Visual Studio Code](https://code.visualstudio.com/)* - замена *[OpenIDE](https://openide.ru/)*. Популярная программа для программирования. Также, Visual Studio Coude тоже **Open Source**!
4. *[Krita](https://krita.org/en/)* - замена *[Inkscape](https://inkscape.org/ru/)*. Минусы: нельзя сразу форматировать SVG и довольно низкое качества просмотра.
